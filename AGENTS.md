# Agent instructions

Before making a Biomiv request or revisiting a research question, read the matching `investigations/*.json` record. Reuse its dated lookups when they still answer the question; add dated observations rather than overwriting changed interpretations. Keep exploratory findings out of curated archive claims until source review supports a change. The canonical archive is `archive/data/kb.json` and related source records; regenerate `archive/archive.json` and the Pages bundle with `npm run build` after canonical archive edits.
